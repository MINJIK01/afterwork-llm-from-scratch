# Step 20 확인 문제 해설

## 1. 드래프트와 타깃의 temperature가 다르면?

정확성 증명은 두 가지만 가정한다. (1) $q$가 드래프트가 **실제로 샘플링한** 분포이고, (2) $p$가 **원하는** 타깃 분포이다. 따라서

- 드래프트를 $\tau_d$로 샘플링하고 수락 판정에도 $\tau_d$로 계산한 $q$를 쓰며, $p$는 원하는 $\tau_t$로 계산하면 → 출력은 정확히 $p$(타깃의 $\tau_t$ 분포)를 따른다. temperature가 달라도 정확하다. 단지 두 분포가 멀어져 수락률이 떨어질 수 있다.
- 드래프트는 $\tau_d$로 샘플링했는데 $q$를 $\tau_t$로 계산해 판정에 쓰면 → (1)이 깨진다. 증명의 첫 항 $q(x)\min(1, p/q)$에서 실제 제안 확률과 판정에 쓴 $q$가 달라 $\min(p, q)$ 형태가 되지 않으므로, 출력 분포가 $p$와 달라진다.

이 레포 구현은 두 모델에 같은 temperature를 쓰고, 실제 샘플링한 분포를 그대로 $q$로 넘긴다.

## 2. $c_d/c_t = 0.1$, $\alpha = 0.7$일 때 최적 $\gamma$

$$\mathrm{speedup}(\gamma) = \frac{1 - \alpha^{\gamma+1}}{(1-\alpha)(0.1\gamma + 1)}$$

| $\gamma$ | 1 | 2 | 3 | **4** | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| speedup | 1.55 | 1.83 | 1.95 | **1.98** | 1.96 | 1.91 | 1.85 |

$\gamma = 4$에서 약 1.98배로 최대이다. 분자는 $\gamma$가 커질수록 $1/(1-\alpha) = 3.33$으로 포화하고, 분모는 선형으로 커지므로 내부 최적점이 있다. $\alpha$가 클수록, $c_d/c_t$가 작을수록 최적 $\gamma$가 커진다.

## 3. Medusa, n-gram 기반 방법과의 비교

| 방법 | 장점 | 단점 |
|---|---|---|
| 별도 드래프트 모델 | 범용. 학습 없이 같은 계열 소형 모델 사용 가능 | 같은 토크나이저 필요. 추가 메모리, 두 모델 서빙과 cache 관리 복잡 |
| Medusa(여러 예측 head) | 모델 하나. 트리 attention으로 여러 후보를 한 번에 검증 | head 학습 필요. 먼 위치 예측 정확도 낮음. 정확한 샘플링 보장은 수락 방식에 따라 다름(typical acceptance는 근사) |
| EAGLE(feature 수준 드래프트) | 타깃 hidden을 이용해 수락률 높음 | 경량 드래프트 레이어 학습 필요 |
| n-gram / prompt lookup | 학습·추가 모델 없음. 비용 거의 0 | 입력을 복사하는 작업(코드 수정, RAG, 요약)에서만 효과적. 자유 생성에서는 수락률 낮음 |

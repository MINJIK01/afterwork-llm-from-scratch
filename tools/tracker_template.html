GitHub 토큰 설정

체크와 메모를 저장하려면 이 레포에만 쓰기 권한이 있는 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되므로 기기마다 한 번씩 입력합니다. 토큰 없이도 진도를 볼 수는 있습니다.

  1. Fine-grained token 만들기를 엽니다.
  2. Repository access: Only select repositories → afterwork-llm-from-scratch
  3. Permissions → Repository permissions → Contents: Read and write (나머지는 기본값)
  4. 생성된 토큰(github_pat_로 시작)을 아래에 붙여 넣습니다.

이 토큰은 같은 계정의 다른 GitHub Pages 사이트와 같은 브라우저 저장 공간을 씁니다. 권한을 이 레포의 Contents로만 제한하고 만료일을 정해 두세요.
